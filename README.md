**What dataset I inspected**
I inspected a BMW car dataset that lists model, price, year it was made, type of transmission, mileage, fuel type, tax, mpg effiency, and engine size.
The dataset comes from here : https://www.kaggle.com/datasets/wardabilal/bmw-cars-dataset-analysis-with-visualizations

**What my field notes contain**
It contains column name, an example value I gave, my inferred data type on this value, and what I think this value represents.

**One important thing I noticed**
It was accurate at the time of making, but it may not be accurate now. At the time the dataset was made, 2020 was the latest year that the list provides.The car market always shifts especially with the popularity of BMW's b58 engine in the past 2 years so, the 3 series back then would be a lot cheaper than a 3 series today. I'm saying 3 series because that is what is listed on the dataset because it does not specify which 3 series, which 5 series, and so forth, but the b58 comes in all cars ending in 40i, so the 3 series 340i, the 4 series 440i, and so on.
